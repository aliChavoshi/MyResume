Architecture & engineering expertise

How I structure systems so they stay reliable and maintainable as they grow.

Clean Architecture & CQRS

Layered separation of Domain, Application, and Infrastructure to reduce coupling and ease long-term maintenance; CQRS to separate read and write paths in enterprise systems.

Microservices & distributed systems

Independent services communicating over RabbitMQ and gRPC, traffic managed through an Ocelot API gateway and Nginx, deployed with Docker and Kubernetes.

Authentication & authorization

Centralized authentication with Identity Server and JWT, role- and access-level management across multi-service, multi-tenant systems.

Database design & caching

Data modeling across SQL Server, PostgreSQL, and MongoDB matched to domain needs, with Redis caching for high-traffic paths to reduce database load.

Scalability & observability

Real-time monitoring for production lines and services, structured logging with Serilog, and API documentation with Swagger for transparency and maintainability.

Testing & CI/CD

Unit test coverage, input validation with Fluent Validation, and automated deployment through GitHub Actions and Docker Compose.

Architecture reconstructed from the repository's docker-compose configuration

Follow a request

  1. The Angular client requests the product list.
  2. Ocelot routes the request to Catalog.API.
  3. Catalog.API reads the products from MongoDB.
  4. The response returns to the client through the gateway.

Engineering decisions

  • Docker and Kubernetes for deployment and service scaling
  • RabbitMQ and gRPC for inter-service communication and messaging
  • Identity Server for authentication and user management
  • SQL Server, MongoDB, PostgreSQL, and Redis for data management
  • Ocelot and Nginx as API gateway and reverse proxy
